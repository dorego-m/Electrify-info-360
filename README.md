# DESCRIPCION DEL PROYECTO 

**Electrify es una plataforma web de monitoreo de consumo eléctrico para empresas. Permite registrar la infraestructura de una organización (sedes, sectores y dispositivos), cargar el uso de cada equipo y calcular automáticamente el consumo en kWh y su costo estimado. A partir de esos datos genera informes por período, identifica los sectores y dispositivos que más consumen, y propone estrategias de ahorro energético para reducir gastos y desperdicio.**
---

#  FUNCIONALIDADES 

- informe de consumo
- consejos personalizados
- registro de dispositivos electrónicos
- Estrategias de optimización del uso de electricidad
